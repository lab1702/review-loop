# review-loop

Loop review-fix-test until review comes clean or 10 reviews are done

This is tested with **Codex** inside the **ChatGPT Desktop** app.

## Installation

### Linux and macOS

```bash
./install_review-loop.sh
```

### Windows

```powershell
.\install_review-loop.ps1
```

## Usage

In the chat window:

```
$review-loop
```
